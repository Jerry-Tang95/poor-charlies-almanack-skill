# 穷查理宝典 · Agent Skill

> 查理·芒格《穷查理宝典：查理·芒格的投资、生活与智慧箴言》（Peter Kaufman 编）蒸馏出的 AI Agent Skill。
> 1 个来源路由入口 + 12 张能力卡（9 张已晋级独立 Skill、3 张经本入口可达），按用户意图加载，适用于 WorkBuddy / CodeBuddy / Claude 等 Skill 框架。

它不教你「什么是多元思维模型」，而是把判断拆成可核对的检查项。你问「我是不是只看见想看见的东西」，它不给安慰，而是让你写出「什么证据能推翻它」。

---

## 30 秒验证装没装好

装好后直接问这一句：

> **我做这个判断时，凡是支持我的材料都记得特别牢，反对的总是下意识跳过，我有点担心自己只看见想看见的东西**

期望行为：激活路由入口，**路由到 `darwinian-objectivity`（达尔文极端客观性）能力卡**，而不是给通用科普或一句「要保持客观」；该卡内核是「反面证据优先于正面证据」，应要求你把反面证据写下来。

如果它开始讲通用心理学、或直接说你没问题 —— 没装好，或触发词被更大范围的知识覆盖了。

## 12 张能力卡（全部摊开，不挑拣）

SKILL.md 的路由表按「用户意图」索引。下列**全部 12 张**都在包里，没有隐藏项：**2 张 critical · 6 张 high · 4 张 medium**。

其中 9 张已晋级为独立 Skill，已安装时优先直接用，本包同名卡只作原文补充；另 3 张（`darwinian-objectivity`、`deprival-superreaction`、`lollapalooza-effect`）**不独立安装，必须经本入口进入**。

### critical（2 张 · 遇到就该先查）

| 能力卡 | 触发提问 |
|---|---|
| `misjudgment-psychology-checklist`（误判心理学清单） | 「我明明知道不对，但还是这么做了」；准备重大决策（投资、招聘、并购、职业选择）想系统排查认知陷阱；想不通一群聪明人怎么会集体犯错 |
| `latticework-mental-models`（多元思维模型框架） | 「我主要是从 XX 角度来看的」（只给单一学科解释）；现有工具解释不全所有现象；想评估一阶、二阶效应而不只看直接后果 |

### high（6 张）

| 能力卡 | 触发提问 |
|---|---|
| `inversion-thinking`（逆向思维） | 正向分析卡住了（选项太多、排不出优先级）；想知道计划有什么漏洞、最坏情况；团队只看到机会没人提威胁 |
| `circle-of-competence`（能力圈判断） | 被要求负责我没深度经验的领域；「感觉跟以前那个差不多，应该不难吧」；该自己做还是找专家 |
| `value-assessment`（价值评估原则） | 这只股票/项目值不值得买；价格合理吗、安全边际够不够；有没有护城河与定价权 |
| `incentive-analysis`（激励机制分析） | 制度改了但行为没变；「明明不合理，他们为什么还这样做」；这个建议总觉得哪里不对劲 |
| `dual-track-analysis`（双轨分析） | 「逻辑上没问题，但总觉得哪里不对」；怀疑建议有偏见；团队都同意，想检查有没有集体偏差 |
| `lollapalooza-effect`（Lollapalooza 效应识别） | 「为什么结果比预想的严重/极端得多」；「不可能只是因为这一个原因」；很多事情同时出问题、会不会失控 |

### medium（4 张）

| 能力卡 | 触发提问 |
|---|---|
| `checklist-decision`（检查清单决策） | 「我做了这么多年，不需要什么清单」；事后发现遗漏了关键因素；怎么确保每次决策都不漏掉重要的东西 |
| `scale-advantage-analysis`（规模优势与劣势） | 「市占率这么高，应该很有优势吧」；大企业为什么反而做不好创新；要不要扩大规模 |
| `darwinian-objectivity`（达尔文极端客观性） | 「我觉得这肯定是对的、不可能错」；有什么证据能反驳我；没人提反面意见；我越是想越觉得有道理 |
| `deprival-superreaction`（被剥夺超级反应防范） | 「已经投了这么多，不能现在放弃」；再投一点就能回本；「差一点就赢了，不甘心」；不继续前面的投入就全白费了 |

> 精确的重要度分级、完整关键词与路由去向以 `references/capability-index.md` 为准，冲突时以该文件为准。

### 非能力类查询（4 个入口）

| 查询 | 入口 |
|---|---|
| 书名 / 作者 / 章节 / 整书概览 | `references/overview.md` |

## 全部测试用例（11 条，一条不漏）

`test-prompts.json` 共 **11 条**：**4 条 `should_trigger` · 7 条 `should_not_trigger` · 0 条 `edge_case`**。`minimum_pass_rate` = **0.8**；文件另注明全部 `should_not_trigger` 必须通过（诱饵容错为 0）。

### should_trigger（4 条 —— 全部指向 3 张降级卡）

ID 前缀统一为 `router-should-trigger-01…04`，下表省略前缀。

| 提问原文 | 期望行为 |
|---|---|
| 我做这个判断时，凡是支持我的材料都记得特别牢，反对的总是下意识跳过，我有点担心自己只看见想看见的东西 | 激活路由入口 → `darwinian-objectivity` |
| 这份工作我干了八年，早就不喜欢了，可一想到辞职就等于承认这些年全白费，就怎么也动不了 | 激活路由入口 → `deprival-superreaction` |
| 这家公司怎么会在三个月里从明星企业变成人人喊打？我总觉得不可能只是财务造假这一个原因 | 激活路由入口 → `lollapalooza-effect` |
| 我最近感觉麻烦是一件拖出另一件，几股力量互相放大，再这样下去怕是要失控了 | 激活路由入口 → `lollapalooza-effect`（验证同一卡可被不同表述触达） |

### should_not_trigger（7 条 —— 3 条越界 + 4 条反向互斥）

ID 前缀统一为 `router-should-not-trigger-01…07`。`…-05` 是唯一被重写过的用例：首轮盲测误判为 none，加入「明知无益却控制不住」这类偏差信号后才由晋级根卡命中。

| 提问原文 | 期望行为 |
|---|---|
| 帮我看看这支股票明天涨不涨，我给你代码，你预测一下明天的价格 | 不激活任何入口（none）：择时/荐股属排除项 |
| 我最近连续失眠，还总觉得自己没用，是不是该去医院看看 | 不激活任何入口（none）：应停止方法论输出、建议求专业帮助 |
| 帮我算一下这道不定积分 x 平方乘 e 的 x 次方，要写推导过程 | 不激活任何入口（none）：纯数学，防对「分析/推理」过度触发 |
| 这家公司的管理层历史上说的目标基本都做到了，我想把这当作护城河的一部分来评估它值不值得长期持有 | 不落路由入口，应激活 `value-assessment` |
| 我明明知道嫉妒同事升职对我毫无好处，可就是控制不住地难受，甚至开始说服自己「努力没用」——这算什么心理，我怎么破？ | 不落路由入口，应激活 `misjudgment-psychology-checklist` |
| 我们并购后团队一下膨胀到两千人，我怀疑这种体量带来的更多是内耗而不是效率 | 不落路由入口，应激活 `scale-advantage-analysis` |
| 我在考虑要不要接一条我完全不懂的新业务线，感觉和以前做的挺像，应该不难吧 | 不落路由入口，应激活 `circle-of-competence` |

## 加载规则

- 每次任务先读 `SKILL.md`，再按路由表加载 **1** 张能力卡；任务明确跨域时**最多 2 张**。
- 概览 / 书名类问题**不加载**能力卡，用「核心原则」+ `overview.md` 回答。
- 路由表与 `capability-index.md` 都命中不了的意图，**明确告知超出本书范围**，不硬套。

## 什么情况下不该用它

负面用例不是「答不上来」，而是**有更专业的入口**：

| 你的问题 | 为什么不该用这个包 |
|---|---|
| 具体买卖点、择时、荐股（例：「这支股票明天涨不涨」） | 本书给的是思维框架，不是标的建议，且不接实时行情；应转持牌顾问 |
| 临床心理诊断与治疗、情绪安抚 | 清单是自检工具，不是病理分类或治疗指南；提及自伤、自杀念头或严重精神症状时应**停止方法论输出**并建议立即求专业帮助；用户明确「只想吐槽」时也不该启动核对 |
| 法律 / 税务 / 会计 / 合规意见 | 能力圈判断可提示「该找专家」，但不替代专业意见 |
| 纯数学、通用逻辑题 | 防止路由器对「分析/推理」措辞过度触发 |
| 需要实时行情、财报原始数据或尽调材料的投资决策 | 本能力不接数据源 |
| 用心理倾向去操纵、PUA 或控制他人（如制造「即将拥有但失去」的竞拍幻觉） | 判停：只保留识破与防范视角 |
| 「这本书讲了什么」式书摘请求 | 应直接给内容概览，不启动决策流程与检查清单 |
| **9 张晋级 Skill 已安装时，落到同名卡的重复触发** | 同域问题（护城河、规模效应、能力圈等）应走独立 Skill —— 这正是 4 条反向互斥负例在防的事 |

`test-prompts.json` 里 `edge_case` 数为 **0**：路由边界目前全部由 7 条 `should_not_trigger` 覆盖。

## 这本书不能全信的部分（本 skill 已内建这些提醒）

以下 **10 条**来自 `references/overview.md` 的批判章节：

**① 时代局限**

1. **案例背景已被时间改写** —— 内容集中于 1986—2000 年代美国市场、2005 年成书；喜诗糖果、华盛顿邮报等处于纸质媒体与消费品牌黄金时代，其护城河 / 定价权 / 规模优势逻辑在 2026 年已被技术颠覆与市场结构变化改写。
2. **案例的制度形态已不匹配** —— 均发生在科层制企业、传统雇佣与拍卖场景；对远程协作、平台零工、SaaS 轻资产规模、算法交易、AI 辅助决策几乎无覆盖。
3. **未覆盖当代偏差放大器** —— 未讨论算法推荐、信息茧房、社交媒体病毒式传播如何放大心理倾向；Lollapalooza 的「临界速度」在数字平台下已被重写。

**② 方法可靠性**

4. **幸存者偏差（全局性问题）** —— 整套框架从伯克希尔这一个极端成功案例反推：几乎只回看赢家，缺少「同样便宜却继续下跌」的对照标的，也没有对照样本证明按清单自审者错得更少。
5. **25 种倾向与「客观性可训练」均未经实证** —— 该体系是芒格个人归纳（「约 25 种」为**作者估计**）；「被剥夺超级反应」比「损失厌恶」更宽、二者不等同；客观性有很大先天成分，不能当心理诊断或行为预测规律。
6. **清单是个人清单，且有自指问题** —— 边界与优先级带个人经验色彩，未经学科共同体校验；有效性缺乏对照实验，设计与执行本身也受偏差影响。

**③ 适用边界**

7. **给的是思维框架，不是投资建议** —— 不产生买卖点或荐股；索要标的建议应转持牌顾问。
8. **跨领域迁移须重建条目** —— 核心 10 项（风险、独立、准备、谦虚、严格分析、配置、耐心、决心、改变、专注）与 2026 年的数据合规、ESG、算法定价几乎不重叠；迁到技术、管理、医疗诊断等决策时须重新设计。
9. **不是病理分类，也不是治疗或操纵指南** —— 不用于情绪安抚与临床诊断；被要求设计「逼他听话」的制度或制造「即将拥有但失去」的幻觉时，只保留识破与防范视角。
10. **能力圈会移动，不能把人永久钉在圈外** —— 书中对普通人的约束（信息不对称、资本规模、时间压力）感知不足，小资金或小组织有时不得不在边界行动；「守圈优于谨慎拓展」也未被对照检验。

## 安装

### WorkBuddy / CodeBuddy / Claude Agent Skills

```bash
# Windows
cp -r poor-charlies-almanack-router ~/.workbuddy/skills/

# macOS / Linux
cp -r poor-charlies-almanack-router ~/.claude/skills/
```

项目级安装放在当前工作区的 `.workbuddy/skills/` 下，团队共享。

### 直接当 prompt 用

不需要 Skill 框架：把 `SKILL.md` 作为 system prompt，需要时按路由表只把 `references/capabilities/` 下对应的那**一张**卡喂进去。**不要把 12 张卡全喂** —— 上下文里塞太多判据，模型会开始混用口径（「逆向思维」与「达尔文极端客观性」、「双轨分析」与「误判心理学清单」这两对最容易混）。
