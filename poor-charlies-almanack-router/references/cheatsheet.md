# 决策规则速查 — 《穷查理宝典：查理·芒格的投资、生活与智慧箴言》

| 能力 | 一句话规则 |
|---|---|
| 误判心理学清单 | 重大判断前把 25 种心理倾向当检查清单逐项自审——先问"哪种倾向正在扭曲我或他的判断"，再动手决策。 |
| 多元思维模型框架 | 逼问"我现在只用了几个学科的模型"，从数学/工程/物理/生物/心理/经济至少再调 3 个模型交叉验证同一结论。 |
| 逆向思维 | 把"怎么才能成功"翻转成"什么一定会导致失败"，列 5 条以上失败路径并逐条设规避措施。 |
| 能力圈判断 | 用否定测试定位边界——需要问自己是否在圈内，答案就是圈外；圈外只做学习路径或找专家，不独立下注。 |
| 价值评估原则 | 先用护城河、安全边际、定价权、管理层、能力圈五维过一遍，再问"股价公道的伟大企业是否胜过股价超低的普通企业"。 |
| 激励机制分析 | 看不懂的行为先问"谁被激励去做什么"；顾问的建议若恰好对他自己有利，就按利益冲突而非专业意见处理。 |
| 双轨分析 | 同一决策跑两条轨——理性轨算清谁控制利益，心理轨逐项排查潜意识偏差；两轨冲突即判为高风险。 |
| 检查清单决策 | 把思维模型、失败教训、心理偏差编成事前强制执行的核对清单，专治"我很有经验，不需要清单"。 |
| 规模优势与劣势 | 同时列规模优势（几何效应/品牌社会认同/分工/寡头/网络效应）与规模劣势（官僚/僵化/信息失真/腐败），再判断净效果与边际递减。 |
| 达尔文极端客观性 | 观点越让自己信服，越要刻意找反面证据并立即记录——找不出让自己不舒服的反证，就无权持有这个观点。 |
| 被剥夺超级反应防范 | 当"已经投了这么多""差一点就赢了"冒出来时，先分离事实与情绪，再强制冷却 24 小时才决定是否加注。 |
| Lollapalooza 效应识别 | 面对极端结果，不满足于单一原因，列出所有作用力量与方向；3 个以上同向叠加即判定为临界质量风险。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
