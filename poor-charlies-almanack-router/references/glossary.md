# 《穷查理宝典》共享术语词典（v2.5 Bundle 书级上下文）

> **本词典由 v2.0 迁移产物归纳，未回源书逐页核对。** 词条全部取自 12 张能力卡实际出现的概念，出处沿用卡片中标注的章节位置。
> 用法约定：下表记录的是**芒格在本书中的特定用法**，不是字典定义；引用时不可替换为常识语义（常见误用在"特定用法"列中点明）。
> 适用范围：本词典是全部能力卡共用的"作者原意"锚点，不独立成 skill。

## 一、思维框架类

| 术语 | 作者的特定用法（不是字典定义） | 出处 |
|---|---|---|
| 格栅思维 / 多元思维模型 | 把经验悬挂在"由许多思维模型组成的框架"上；模型必须来自不同学科，重点是**组合使用能力**而非知识广度；约 100 个模型中"非常重要的只有几个"，须终身操练（不用就忘）。≠ 博学多才式的知识积累 | 第二讲（论基本的、普世的智慧）；第三讲（修正稿）；第十一讲 |
| 铁锤人倾向 | "在手里拿着铁锤的人看来，每个问题都像钉子"——只用单一学科解释一切。是格子思维的失败模式，也是识别"该扩维了"的信号 | 第二讲 |
| 能力圈 | 真正能做出准确判断的知识与经验边界。关键**不是圈多大，而是是否清楚边界在哪**；衡量标准是经实战验证的判断准确率，不是主观熟悉度 | 第二章（能力圈及其边界）；第三讲（答问录）；第二讲 |
| 否定测试 | 能力圈的操作判据："如果你问自己是否过了能力圈的范围，那这个问题本身就是答案。"——需要问，即已在圈外。与"舒适区"无关（舒适区外仍可能在圈内） | 第二章（能力圈及其边界） |
| 逆向思维（反过来想） | 系统的首要推理策略，不是偶用技巧：先问"什么会导致失败"，列清单再逐条设规避。核心假设是人对"不想要什么"的判断比"想要什么"更清晰可靠；成功靠避免愚蠢而非追求聪明 | 第一讲（哈佛学校毕业典礼演讲）；第二讲；第十一讲 |
| 投资原则检查清单 | **强制性思维校准工具**，不是待办事项或备忘录；条目内容是思维模型 + 失败教训 + 心理偏差。书中第二章末列为 10 项：风险、独立、准备、谦虚、严格分析、配置、耐心、决心、改变、专注。核心价值在"事前强制执行"，用于防"聪明人自认聪明而跳过检查" | 第二章·投资原则检查清单；第十一讲 |
| 双轨分析 | 同一决策跑两条轨道。第一轨（理性）：哪些因素**真正控制了涉及的利益**；第二轨（心理）：大脑在潜意识状态下会自动形成哪些心理因素。第二轨是系统化的（25 种倾向逐项检查），≠ 跟着感觉走 | 第二章（芒格的生活、学习和决策方法）；第四讲；第十一讲 |
| 达尔文式极端客观性 | 优先级反转：**反面证据比正面证据更重要**，"无论他对这种理论有多么珍惜"。一旦发现与已有理论不符的事实要立即记录，因为人脑会自动忘记不利证据。≠ 谦虚习惯；也≠ 用搜索反证来"证明自己很客观" | 第一讲（哈佛学校毕业典礼演讲）；第十一讲（倾向五） |
| 冲浪模型 | 新行业先行者如何冲上技术/需求的浪尖（以及像 IBM 那样"冲浪 60 年后从浪尖掉落"）。关注的是**尚未站稳时的时机**，与规模分析关注的"站稳后规模是福是祸"阶段不同 | 第二讲 / 第三讲（微观经济学部分） |

## 二、心理倾向类（人类误判心理学）

| 术语 | 作者的特定用法（不是字典定义） | 出处 |
|---|---|---|
| 误判心理学 / 人类误判心理学 | 芒格自建的一套**面向决策的实用清单体系**（约 25 种倾向），每种配真实案例与防范方法。≠ 学术心理学分类，也不是诊断他人的工具；强调多种倾向的交互效应而非孤立分析 | 第四章·第十一讲·人类误判心理学 |
| 奖励和惩罚超级反应倾向 | 25 种倾向之首，威力超过其他一切因素："人们不是按你说的做，而是按他们被激励的方向做"；说服要诉诸利益而非诉诸理性 | 第十一讲（倾向一） |
| 激励机制引起的偏见 | 即使受过高等教育、道德高尚的人，也会在激励驱动下有意或无意做出不道德行为，**并真心为自己的行为寻找正当理由**。隐蔽性与不可抗拒性是重点，≠ 常识"人趋利" | 第十一讲（倾向一） |
| 避免不一致性倾向 | 一旦形成结论或已投入，就本能排斥与之矛盾的新信息；是**沉没成本谬误的心理根源**，范围超出损失情境（也包括不愿改变已有观点） | 第十一讲 |
| 被剥夺超级反应倾向 | 失去带来的痛苦远大于同等获得的快乐，且这种不对称是非线性的、损失越大增长越快。独特之处：**"即将拥有但失去"同样触发**（差一点就赢、拍卖被超过），且可被恶意设计利用 | 第十一讲（倾向十四） |
| 社会认同倾向 | 因"大家都这么想/这么做"而接受某个判断；在公开竞拍中使竞买者相信他人报价合理，是群体行为的驱动之一 | 第十一讲 |
| 权威错误影响倾向 | 权威的施压或示范使人做出违背自身判断的行为（米尔格拉姆实验、麦道撤离测试、库克船长让官员先吃酸泡菜均为其正反用法） | 第十一讲 |
| 避免怀疑倾向 | 急于快速做出决定，之后拒绝改变。常与权威影响、社会认同同向叠加造成极端后果 | 第十一讲 |
| 第一结论偏见 / 确认偏见 | 快速形成的第一个结论会被避免不一致性锁定，此后很难改变；大多数人"早年取得成就后就越来越拒绝新的、证伪性的信息"。达尔文是化解它最成功的人 | 第十一讲（倾向五） |
| 过度乐观倾向 | "一个人想要什么，就会相信什么"——是逆向分析与风险清单被架空成走过场的主因 | 第一讲；第十一讲 |
| 喜欢 / 热爱 与 讨厌 / 憎恨倾向 | 因"爱"上某个方案而自动忽略其缺点，或因讨厌某人某方案而自动忽略其优点；是双轨分析第二轨的必查项 | 第十一讲 |
| 避免痛苦的心理否认 | 通过扭曲现实来保护心理（而非通过加注"扳回"），使人在已失败的事实面前失明；与避免不一致性、被剥夺超级反应同向叠加时是破产链条的第三股力量 | 第十一讲 |
| 自视过高倾向 | 对自身能力与判断准确率的系统性高估（"瑞典有 90% 的司机都认为自己的驾驶技术在平均水平之上"），直接导致能力圈边界的误判 | 第十一讲 |
| 废话倾向 | 面对不了解的问题时仍自动、自信地生成"答案"，而非承认不知道（韦尔奇答"我没有足够的能力来回答这个问题"为正确示范） | 第十一讲 |
| 错误衡量易得性倾向 | 只用容易得到、容易量化的因素做分析，忽略不容易量化但关键的因素；是"减少操练即退化为铁锤人"的伴生失败模式 | 第二讲 / 第三讲 |
| Lollapalooza 效应 | 两三种（或四种）力量**同向**作用时，结果"通常不仅仅是几种力量之和"，而是临界质量式的非线性爆发；是理解泡沫、群体疯狂、组织崩盘等极端事件的钥匙。≠ 蝴蝶效应 / 一般叠加效应 | 第四章·第十一讲（第二十五倾向）；第二讲；第三讲 |
| 临界质量 | 物理学类比：达到一定程度的"质量"就引发核爆炸，**没有达到则什么也得不到**。用于判断多因素叠加是"仍在积累"还是"已经引爆" | 第二讲 |

## 三、投资评估类

| 术语 | 作者的特定用法（不是字典定义） | 出处 |
|---|---|---|
| 安全边际 | 买入价格远低于内在价值，为判断错误留出保护空间。芒格对格拉汉姆的关键修正：**安全边际不一定来自超低价格，也可以来自企业本身的卓越质量**；须写出具体百分比与"我可能看错"的假设 | 第二章·投资评估；第二讲 / 第三讲 |
| 护城河 | 企业可持续的竞争优势，须从产品、市场、商标、雇员、分销渠道、社会潮流六个维度逐一检验；判断口径是"为什么客户不会转向竞争对手" | 第二章·投资评估 |
| 定价权 | 企业仅通过提高价格就能极大提升利润的能力，是伟大企业的核心标志；客户价格敏感度极低、产品不可替代 | 第二章·投资评估 |
| 尚未利用的提价能力 | 少数企业的管理者"仅通过提高价格就能极大地提升利润——然而他们还没有这么做"；芒格称其为伟大企业最可靠的标志之一（喜诗糖果、可口可乐） | 第二章·投资评估（A1 案例 3） |
| 股价公道的伟大企业 vs 股价超低的普通企业 | 全书最著名的价值判断修正：前者胜过后者。卓越质量的长期复利效应可以跑赢平庸企业的超低买入价 | 第二章·投资评估 |
| 捡烟蒂 | 只找超低价标的的格拉汉姆式做法（含"只买便宜货"的单一思维）；被芒格修正为综合评估企业质量、管理层、品牌的多维框架 | 第二章·投资评估；第二章（B 段） |
| 20 格考勤卡 | 巴菲特的思想实验：假设一生只能投资 20 次，迫使投资者只在**能力圈内的最高确信度机会**上下注；与"98% 的时间保持不可知状态、不频繁交易"配套 | 第二章（能力圈及其边界） |
| 市场先生 / 彩池投注模型 | 市场先生是价值评估的**情绪管理工具**（不在恐慌时卖出、不在狂热时买入）；彩池投注模型是"寻找定错价机会"的具体操作方法。二者都不是独立方法论 | 第二章·投资评估（邻近方法论对照） |
| 规模优势 | 五类来源分别判定：几何效应（产量的平方/立方关系降低单位成本）、信息优势（高品牌知名度带来的社会认同加成）、专业化分工、寡头垄断（赢家通吃）、网络效应（用户越多产品越有价值） | 第二讲 / 第三讲（微观经济学部分） |
| 规模劣势 | 同样真实存在：官僚主义导致信息过滤与决策迟缓、组织僵化使创新受阻、势力范围争夺消耗资源、腐败风险随层级上升。与规模优势的张力是永恒的——不存在"越大越好" | 第二讲 / 第三讲 |
| 竞争性毁灭 | 优势被颠覆的风险，芒格反复强调的"无情的力量"；规模优势从不是永久的 | 第二讲 / 第三讲 |

## 附：易混术语对（供 agent 消歧）

```
分析要广 ⟷ 行动要窄
  多元思维模型（扩展维度）  ⟷  能力圈判断（收缩范围）

"我在判断中有偏差吗" ⟷ "这个方案本身有致命漏洞吗"
  双轨分析（轨道并行，查判断者）  ⟷  逆向思维（方向反转，查方案）

构建方案 ⟷ 检验结论
  逆向思维（先列失败路径，搭方案）  ⟷  达尔文极端客观性（找反面证据，压力测试）

单一偏差 ⟷ 多偏差叠加
  误判心理学清单（逐项识别）  ⟷  Lollapalooza 效应（同向叠加的临界爆发）

规模是福是祸 ⟷ 规模优势是否会被颠覆
  规模优势与劣势（双面净效果）  ⟷  竞争性毁灭（外部颠覆风险）

沉没成本的心理根源 ⟷ 损失情境的偏差预警
  避免不一致性倾向（更广）  ⟷  被剥夺超级反应倾向（专指对"失去"的非线性反应）
```

**使用硬约束**：本词典词条均为分析、设计与自检工具，不是心理诊断分类，也不是对个体行为的预测规律；引用"25 种倾向"时须与"个人归纳、未经实验心理学验证"这一限定同时出现。涉及具体投资决策时，本书给的是思维框架，不构成投资建议。
